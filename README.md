# Disciplines VTM v20

Модуль для **Foundry Virtual Tabletop**, добавляющий компендиум дисциплин для Vampire: The Masquerade V20.

## Установка

**Установка через Foundry VTT:**

1. Открой Foundry VTT.
2. Перейди в Add-on Modules → Install Module.
3. Вставь ссылку на манифест:

   **https://github.com/HedgehogInTheGasMask/disciplines-VtM-v20-foundry-VTT-module/releases/latest/download/module.json**

4. Нажми Install.

## Содержимое

- **Дисциплины** — компендиум с дисциплинами Vampire: The Masquerade V20.

## Совместимость

- Foundry VTT: Version 12
- Система: World of Darkness
- Версия модуля: 1.0.0
